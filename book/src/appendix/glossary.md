# Glossary

| Term            | Meaning                                                                  |
|-----------------|--------------------------------------------------------------------------|
| **ABI**         | Application Binary Interface — frozen contracts in `crates/abi/`.       |
| **ADR**         | Architectural Decision Record — module-local design decision.           |
| **APS**         | Adaptive Partitioning Scheduler — RFC-0004.                             |
| **ASIL**        | Automotive Safety Integrity Level — ISO 26262.                          |
| **AUTOSAR-AP**  | AUTOSAR Adaptive Platform — automotive standard. RFC-0015 subset.       |
| **BMC**         | Bounded Model Checker — what Kani is.                                   |
| **CAPS.TOML**   | Capability assignment file — RFC-0005.                                  |
| **`Cap<T>`**    | Typed capability handle — RFC-0003.                                     |
| **CBS**         | Constant Bandwidth Server — scheduler component, RFC-0004.              |
| **CRA**         | EU Cyber Resilience Act — supply-chain regulation.                      |
| **DCO**         | Developer Certificate of Origin — git commit sign-off.                  |
| **EDF**         | Earliest Deadline First — scheduler policy, RFC-0004.                   |
| **ESTOP**       | Emergency stop — kernel-enforced safety.                                |
| **HW-ROT**      | Hardware Root of Trust — RFC-0011.                                      |
| **HIL**         | Hardware-in-the-Loop — CI testing on real silicon.                      |
| **IPC**         | Inter-Process Communication.                                            |
| **LTS**         | Long-Term Support release — RFC-0016.                                   |
| **MBL**         | Model Bundle — AI artefact format, RFC-0007.                            |
| **MMIO**        | Memory-Mapped I/O.                                                      |
| **NPU**         | Neural Processing Unit.                                                 |
| **OTA**         | Over-the-Air firmware update — RFC-0011.                                |
| **OTP**         | One-Time Programmable — eFuse storage.                                  |
| **PHANES**      | Greek primordial deity of light + creation. The project name.           |
| **PSIRT**       | Product Security Incident Response Team — RFC-0009 + RFC-0016.          |
| **RFC**         | Request For Comments — design document, see `rfcs/`.                    |
| **SBOM**        | Software Bill of Materials — RFC-0012.                                  |
| **SCHED.TOML**  | Scheduler partition + policy file — RFC-0005.                           |
| **SLSA**        | Supply-chain Levels for Software Artefacts — RFC-0012.                  |
| **TARA**        | Threat Analysis & Risk Assessment — ISO 21434.                          |
| **TLA+**        | Temporal Logic of Actions — formal-spec language.                       |
| **TLC**         | Tool that checks TLA+ specs.                                            |
| **TSC**         | Technical Steering Committee — RFC-0009.                                |
| **TSR**         | Technical Safety Requirement — ISO 26262.                               |
| **W^X**         | Write-XOR-Execute — memory-permission invariant.                        |
